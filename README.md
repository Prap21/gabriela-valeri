# 🛍️ Gabriela Valeri — Modern E-Commerce Website

A modern, fully responsive e-commerce web application designed for custom shoe retail. Built to deliver a seamless shopping experience from product discovery all the way to checkout.

---
🚀 **Live Demo:** Try the live version here: [Gabriela Valeri](https://Prap21.github.io/gabriela-valeri/)

## ✨ Key Features

* **📱 Modern & Responsive Design:** Elegant UI tailored for shoe collections, looking great on mobile, tablet, and desktop.
* **🛍️ Dynamic Shopping Experience:** Interactive product catalog, category filters, detailed product pages, and size selector.
* **🛒 Guest Cart:** Smooth, persistent cart system where users can easily add, review, and adjust items.
* **💳 Complete Checkout Flow:** Integrated with **Stripe Checkout** to handle test payments seamlessly.

---

## 🛠️ Built With

* **Frontend:** React.js, Context API, CSS3
* **Backend:** Node.js, Express API
* **Payments:** Stripe API
